The first release of Clipnest, a lightweight, keyboard-first clipboard manager for Linux
(GNOME, GTK 4 / libadwaita), written in Rust and based on the design of
[Maccy](https://maccy.app) (not affiliated).

> [!WARNING]
> **This project was generated entirely by AI (Claude Opus 5.5, max effort).** It has been
> tested, but no human has reviewed the code line by line. **Use with caution**: it reads
> your clipboard, which can contain sensitive data.

## Highlights

- **History window** with exact, fuzzy, regex or mixed search, pins with their own Ctrl+key,
  a details pane, and keyboard control throughout.
- **A notification for every copy** (optionally without the copied text).
- **Text in images is searchable**: recognized locally with Tesseract (optional).
- **Sensitive copies stay off the disk**: API keys, tokens, private keys, passwords in links
  and `KEY=value` lines, card and ID numbers (also in screenshots) are shown masked, kept in
  memory only and removed after 30 s, from the clipboard too.
- **Hidden-character and dangerous-command warnings**, with one click to copy a cleaned
  version (or optional automatic cleaning).
- **Paste in order**: each Ctrl+V pastes the next item. Handy for forms.
- **Quick conversions**: timestamps, JSON, URL, Base64, JWT, and colors (HEX/RGB/HSL).
- Panel menu with thumbnails and color swatches, optional global shortcut and launch at login.

See the [README](https://github.com/Rong0715/clipnest#readme) for screenshots.

## Install

For x86_64 Linux with GTK 4.14+ and libadwaita 1.5+, e.g. Ubuntu 24.04 or newer (built on
24.04, tested on 26.04 with GNOME 50; other distributions with these versions should work
but are untested). Installs for your user only, into `~/.local`:

```sh
tar xzf clipnest-0.1.0-x86_64-linux.tar.gz
cd clipnest-0.1.0-x86_64-linux
./install.sh
```

Then open **Clipnest** from the app grid. To search text in images, also install
`tesseract-ocr` (and language packs such as `tesseract-ocr-chi-sim`). To remove it, run
`./uninstall.sh` (add `--purge` to delete the history too).

Check the download with `sha256sum -c clipnest-0.1.0-x86_64-linux.tar.gz.sha256`.
